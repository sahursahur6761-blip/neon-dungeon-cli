# Neon Dungeon CLI

An offline Python terminal roguelite game.

## 🚀 Quick Start (Global Install)
Run this command in the repository root:
```bash
pip install .
```
Now you can start the game from anywhere by typing:
```bash
neon-dungeon
```

## Features
- **3 Unique Classes**: Cyberslasher, Tank, and Netrunner.
- **Persistent Meta-Progression**: Buy permanent upgrades in the Synapse Hub.
- **Dynamic Sectors**: Explore Slums, Hive, and Mainframe with unique visuals and bosses.
- **A* Pathfinding AI**: Enemies navigate the dungeon intelligently.
- **Loot & Equipment**: Weapons, Armor, and Cyber-Augmentations.

## Global Installation
You can install Neon Dungeon globally and run it from anywhere in your terminal:

1. Clone or download the repository.
2. Navigate to the project root.
3. Run: `pip install .`

Now you can start the game simply by typing:
```bash
neon-dungeon
```

## How to Play
- **WASD / Arrows**: Move and Attack
- **Space**: Start / Action
- **'f'**: Fire Ranged Weapon
- **'e'**: Use Class Skill
- **'i'**: Inventory
- **'?'**: In-game Help
- **'v'/'l'**: Save/Load Game
